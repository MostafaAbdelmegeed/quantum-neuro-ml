# First learned graph representation

Specified on 2026-10-22 before fitting the graph encoder to ABIDE. The [v4 configuration](../config/graph-v4.json) extends the exploratory [v2 protocol](follow-up-protocol.md). The cohort, acquisition-group folds, metrics, nuisance regression, and kernel-readout grids stay the same. Report both raw and residual edges and every readout. This is the first compact graph baseline; GIN and other graph architectures remain future comparisons.

Reconstruct each participant's symmetric 200-node Fisher-z matrix with zero diagonal. Keep positive and negative weights in separate channels. For each graph let `D[i] = 1 + sum_j abs(W[i,j])`, then use `D^-1/2 max(W,0) D^-1/2` and `D^-1/2 max(-W,0) D^-1/2` for neighbour messages. Each layer also has a separate linear transformation of the node's own features. This avoids taking square roots of signed degree sums.

Node features concatenate connectivity profiles and eight spectral coordinates. Standardise each edge using the current training partition only, then reconstruct the profile matrix. Derive spectral coordinates separately from each participant's absolute-weight graph: use the eight nontrivial eigenvectors of its symmetric normalised Laplacian, ordered by eigenvalue, and flip each vector so its largest absolute entry is positive. No aggregate spectral basis or held-out-participant statistic is fitted. Nearly repeated eigenvalues can make these coordinates unstable; record the minimum adjacent eigengap as a diagnostic. Spectral coordinates are an initial design choice, not a claim of a unique graph embedding.

The encoder has two signed message layers of width 16 with ReLU, with dropout 0.2 after the first layer. Concatenate mean and maximum node pooling, then map to a four-dimensional tanh embedding. During encoder fitting, train a linear diagnosis logit from that embedding using Adam, class-balanced binary cross-entropy, learning rate 0.001, weight decay 0.0001, batch size 16, 40 fixed epochs, and seed 42. Use float32 CPU arithmetic. There is no test-based stopping or encoder hyperparameter search in this first experiment.

Fit the supervised encoder from scratch inside each inner training partition and again in the outer training data. Discard the training logit head and freeze the encoder before fitting each readout. Cache only identical training-input/target fits so the four readouts share exactly the same encoder. Standardise the four embedding coordinates using the current training partition and apply `pi*tanh(z/2)`. Compare logistic, RBF, polynomial, and exact quantum fidelity-kernel SVM readouts with the v2 grids, selecting readout parameters in the inner acquisition-group folds. Verify participant and actual representation fingerprints across readouts.

The encoder has a much larger parameter budget than the final readouts. The matched comparison concerns the readouts conditional on this shared learned representation. Training the encoder on the entire cohort before cross-validation would invalidate this experiment. A positive result here still needs more seeds, graph ablations, and independent validation.

Preflight checks cover signed normalisation, graph-message permutation invariance, finite training gradients, deterministic fitting, and training-only feature scaling. A synthetic nested evaluation must complete and verify shared representations before the full cohort run.
